NextGen AIR Academy is a comprehensive AI training platform designed to empower overlooked talent with market-ready skills in AI-driven systems integration. Our mission is to bridge the critical chasm between regional skills shortages and untapped human potential through equitable access to advanced digital integration.

## 🎯 Mission

The NextGen AIR Academy is built on a vision where overlooked talent leads the AI-powered economy. We bridge the critical chasm between regional skills shortages and untapped human potential through equitable access to advanced digital integration. Our mission is to equip Dayton's most valuable resource with market-ready skills in AI-driven systems integration, empowering individuals to secure high-demand careers while helping local organizations modernize their technology with an ethical, human-centered approach.

## 🚀 Features

### 📚 Comprehensive Curriculum
- **Prompt & Context Engineering**: Mastering precise LLM inputs for business applications
- **AI Workflow Development**: Building no-code/low-code agents (Zapier/Make.com)
- **Basic ML Workflows & APIs**: Introduction to supervised learning and REST APIs
- **AI-Powered Business Analytics**: Utilizing Tableau and PowerBI
- **MCP Servers & Deployment**: Capstone course on cloud orchestration

### 🏗️ Technical Stack
- **Frontend**: Next.js 16.1.6 with React 19.2.3
- **Styling**: Tailwind CSS 4.x with custom design system
- **Type Safety**: TypeScript 5.x
- **Deployment**: Vercel with automatic CI/CD
- **Linting**: ESLint with Next.js configuration

### 🎨 Design System
- Responsive design with mobile-first approach
- Accessibility-focused components
- Custom UI components built with modern React patterns
- Professional branding and visual identity

## 📖 Curriculum Overview

The 52-week certification track provides students with five industry-recognized credentials:

1. **Prompt & Context Engineering** - Microsoft AI Associate Level
2. **AI Workflow Development** - Automation/No-Code Specialist
3. **ML Workflows & APIs** - AWS/Google Cloud ML Foundations
4. **Business Analytics** - Tableau Desktop / PowerBI Data Analyst
5. **MCP Servers & Deployment** - Cloud Solutions Architect (Associate)

## 🛠️ Installation & Setup

### Prerequisites
- Node.js 18+ 
- npm or yarn package manager

### Local Development

1. **Clone the repository**
   ```bash
   git clone [your-repository-url]
   cd nextgen-air
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open your browser**
   Visit [http://localhost:3000](http://localhost:3000) to see the application

## 🚀 Deployment

This project is configured for deployment on Vercel with automatic CI/CD:

1. **Connect to Vercel**
   - Import the GitHub repository to Vercel
   - Configure environment variables if needed
   - Deploy automatically on git push

2. **Manual deployment**
   ```bash
   npm run build
   npm start
   ```
